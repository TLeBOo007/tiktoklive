# ไลฟ์ศาลเจ้ามูเตลู

## เตรียมครั้งเดียว
1. ติดตั้ง **Node.js LTS** จาก https://nodejs.org (กด Next ไปจนจบ)
2. แตกไฟล์ zip ไว้ที่ไหนก็ได้ เช่น Documents\shrine-live
3. เปิด `config.json` ด้วย Notepad แก้บรรทัด `"username": "ใส่ชื่อบัญชี"` เป็นชื่อบัญชี TikTok ของคุณ (ไม่ต้องใส่ @) แล้วกดบันทึก

## ทดสอบก่อน (ไม่ต่อ TikTok)
ดับเบิลคลิก `start-demo.bat` จะมีหน้าต่างเกมเด้งขึ้นมา และมีคนดูปลอมเข้ามาไหว้เอง
ปิดหน้าต่างดำ (cmd) เพื่อหยุด

## ขึ้นไลฟ์จริง
1. เปิด TikTok LIVE Studio
2. ดับเบิลคลิก `start.bat` จะมีหน้าต่างเกม (แนวตั้ง) เด้งขึ้นมา
3. ใน Studio: เพิ่มแหล่งภาพ (Add source) → **จับหน้าต่าง (Window capture)** → เลือกหน้าต่าง "ไลฟ์ศาลเจ้ามูเตลู"
4. ตั้ง Studio เป็นแนวตั้ง (Portrait) แล้วลากภาพเกมให้เต็มจอ
5. กด Go LIVE ใน Studio
6. ดูหน้าต่างดำ ต้องขึ้นว่า `เชื่อมต่อ TikTok สำเร็จ` (ถ้ายังไม่ขึ้น มันจะลองใหม่เองทุก 15 วินาที)

ห้ามย่อหน้าต่างเกมลง (minimize) ระหว่างไลฟ์ ไม่งั้นภาพจะค้าง ให้วางไว้ข้างหลังได้

## ปุ่มทดสอบในหน้าต่างเกม (คลิกที่หน้าต่างเกมก่อน)
| ปุ่ม | ผล |
|---|---|
| F | มีคนติดตาม |
| 1 / 2 / 3 / 4 | จุดธูป / เซียมซี / ลอยโคม / เสริมดวง |
| S | คอมเมนต์ "สาธุ" |
| L | หัวใจลอย |

ระวัง: ถ้ากดตอนไลฟ์อยู่ คนดูจะเห็นด้วย

## ของขวัญกับเอฟเฟกต์ (แก้ได้ใน config.json → giftTiers)
| เหรียญรวมที่ส่ง | เอฟเฟกต์ |
|---|---|
| 1 ขึ้นไป | 🌹 จุดธูป |
| 5 ขึ้นไป | 🎋 เขย่าเซียมซี มีใบทำนายขึ้นจอ |
| 20 ขึ้นไป | 🏮 ลอยโคมสะเดาะเคราะห์ |
| 100 ขึ้นไป | ✨ เสริมดวงทั้งศาลเจ้า ฝนทอง ชื่อขึ้นกลางจอ |

อื่นๆ: กดติดตาม = ตัวละครเดินมาไหว้, คอมเมนต์ "สาธุ" = ไหว้, คอมเมนต์ "เกิดวันพุธ" = บอกสีมงคล, กดหัวใจ = หัวใจลอย

## ถ้ามีปัญหา
- **หน้าต่างดำขึ้นว่าเชื่อมต่อไม่ได้**: ตรวจว่าเปิดไลฟ์อยู่จริงและชื่อบัญชีใน config.json ถูกต้อง
- **ขึ้นเรื่อง rate limit / sign**: โปรแกรมใช้บริการฟรีของ Euler Stream ที่มีโควตาจำกัด ขอ API key ที่ eulerstream.com แล้วใส่ใน `signApiKey`
- **หน้าต่างเกมไม่เด้ง**: เปิด Edge แล้วพิมพ์ `http://localhost:3000/?live=1` เอง
- **อยู่ๆ ใช้ไม่ได้หลัง TikTok อัปเดต**: เปิด cmd ในโฟลเดอร์นี้แล้วพิมพ์ `npm update tiktok-live-connector`

คำทำนายเป็นข้อความทั่วไปเพื่อความบันเทิง ไม่ควรโฆษณาว่าได้ผลจริง
