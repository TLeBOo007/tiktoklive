# ศึกมวยไลฟ์ (TikTok LIVE โต้ตอบ)

## ใช้บน Railway
- ตัวแปร `TIKTOK_USERNAME` = ชื่อบัญชีหลัง @ (ไม่ใช่ชื่อที่แสดง)
- เปิดหน้าเกม: `https://(ลิงก์ของคุณ)/?live=1` ใน Microsoft Edge แล้วให้ TikTok LIVE Studio จับหน้าต่าง (Window capture)
- เช็กสถานะ: `/status` · สั่งต่อ TikTok ใหม่ (หลังเปิดไลฟ์ใหม่): `/reconnect`
- หลังเปิดหน้าเกม **คลิกหน้าต่าง 1 ครั้ง** เพื่อเปิดเพลง เสียงประกอบ และเสียงพากย์
- ใน Studio เปิดการจับเสียงคอม (Desktop audio)

## กติกา
- **ยังไม่มีแชมป์:** คนแรกที่ส่งของขวัญ ได้เป็นแชมป์เวที (มุมแดง คาดเข็มขัดทอง)
- **คิวท้าชิง:** ทุกคนที่ส่งของขวัญจะเข้าคิว ใครส่งรวมมากได้ขึ้นชกก่อน (มุมน้ำเงิน)
- **ชก 3 ยก** ยกละ 45 วินาที พัก 4 วินาที นักมวยออกหมัดเองเบาๆ
- **ของขวัญระหว่างชก:**
  - ถ้าคนส่งเป็นนักมวยเอง = ออกท่าใส่คู่ชก
  - คนดูคนอื่น = ช่วยข้างที่เลือกไว้ (พิมพ์ "แดง" หรือ "น้ำเงิน" ในแชท ถ้าไม่เลือก จะช่วยมุมน้ำเงิน) และได้เข้าคิวด้วย

| เหรียญ | ท่า | ความแรง |
|---|---|---|
| 1 | 👊 หมัด | ~6 |
| 5 | 🦵 เตะ | ~13 |
| 20 | 💥 ศอก | ~27 |
| 100 | 🔥 เข่าลอย | ~60 |

- พลังชีวิตคนละ 100 หมดก่อน = แพ้น็อก · ครบ 3 ยก = ตัดสินจากพลังที่เหลือ (เสมอ แชมป์ป้องกันได้)
- ผู้ท้าชิงชนะ = เป็นแชมป์ใหม่ · แชมป์ชนะ = นับ "ป้องกันแชมป์" เพิ่ม
- เซิร์ฟเวอร์จำแชมป์ไว้ โหลดหน้าใหม่ไม่หาย

## ปุ่มทดสอบ (คลิกหน้าต่างเกมก่อน · ห้ามกดตอนไลฟ์อยู่ คนดูจะเห็น)
| ปุ่ม | ผล |
|---|---|
| F | มีคนเข้ามา |
| 1 / 2 / 3 / 4 | คนสุ่มส่ง 1 / 5 / 20 / 100 เหรียญ |
| 5 | แชมป์ส่งเตะ |
| 6 | ผู้ท้าชิงส่งศอก |
| R / B | คนสุ่มพิมพ์ "แดง" / "น้ำเงิน" |
| L | หัวใจลอย |

ทดสอบเสร็จแล้ว กด Ctrl + F5 แล้วเปิด `/reconnect` ก่อนขึ้นไลฟ์ (ล้างแชมป์จากการทดสอบได้ด้วยการ Restart ใน Railway)

## เสียง
- เพลงปี่กลองมวยไทย สร้างสดในเบราว์เซอร์ (ไม่ใช่ไฟล์เพลง) เร็วขึ้นตอนชก
- เสียงระฆังเริ่มยก หมัด เตะ ศอก เสียงกองเชียร์ น็อก
- เสียงพากย์: ประกาศคู่ชก ยก ท่าแรงๆ น็อก แชมป์ใหม่ (ใช้ Edge จะมีเสียงไทย)
- ปิด: `&music=0` เพลง · `&sfx=0` เสียงประกอบ · `&tts=0` เสียงพากย์

## ปรับราคาของขวัญ
แก้ `giftTiers` ใน `config.json` (action: `jab`, `kick`, `elbow`, `knee`)

## ถ้ามีปัญหา
- คนเข้าแล้วไม่ขึ้น: เปิด `/status` ดู `connected`, `roomId`, `secondsSinceData` แล้วลอง `/reconnect`
- ขึ้นเรื่อง rate limit / sign: ขอ API key ที่ eulerstream.com ใส่ตัวแปร `SIGN_API_KEY`

เกมนี้เพื่อความบันเทิง ไม่มีการเดิมพันหรือรางวัลเป็นเงิน
